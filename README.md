# CrimsonCraftAssets
В данной папке содержатся скины, локации с ныне закрытого сервера **CrimsonCraft**.
Сервер фактически был создан ещё в **2020** году и проработал вплоть до **декабря 2024** года, после чего закончил существование на фоне последнего события которое завершило франшизу.
